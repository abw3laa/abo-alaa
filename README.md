# متجر أبو علاء (Abo-alaa) — متجر إلكتروني احترافي

متجر إلكتروني متعدد الأقسام لبيع الملابس والأحذية والإكسسوارات والإلكترونيات الخفيفة ومنتجات المنزل. مبني بـ **Next.js 15** و **PostgreSQL** و **Prisma**، بواجهة عربية RTL كاملة ولوحة تحكم متقدمة للمدير.

> ملاحظة: المشروع مصمم للتشغيل والبناء بالكامل عبر السحابة (GitHub Actions + Vercel + قاعدة بيانات سحابية) دون الحاجة إلى تشغيل محلي.

## المميزات الأساسية

- واجهة عربية RTL احترافية مع دعم إنجليزي LTR وتبديل فوري.
- دعم عملات متعددة (ل.ت / $ / €) وتنسيق أسعار وتواريخ حسب اللغة.
- الوضع الليلي Dark Mode.
- هوية لونية فخمة (كحلي + ذهبي) وخط IBM Plex Sans Arabic.
- نظام مصادقة آمن (Auth.js v5 + Argon2id).
- نظام أدوار وصلاحيات RBAC محمي من الخادم (8 أدوار).
- قاعدة بيانات شاملة (منتجات، متغيرات، طلبات، مدفوعات، شحن، كوبونات، مراجعات، مدونة...).
- Soft Delete و UUID و Audit Logs.
- بنية Modular قابلة للتوسع مع فصل منطق الأعمال عن الواجهة.
- توافق SEO و WCAG 2.2 AA.

## 1) تثبيت الاعتماديات

```bash
npm install
```

## 2) إعداد ملف البيئة

انسخ ملف المثال واملأ القيم:

```bash
cp .env.example .env
```

ولّد مفتاح المصادقة:

```bash
npx auth secret
```

أهم المتغيرات:

| المتغير                                    | الوصف                               |
| ------------------------------------------ | ----------------------------------- |
| `DATABASE_URL`                             | رابط اتصال PostgreSQL               |
| `AUTH_SECRET`                              | مفتاح تشفير الجلسات (إلزامي)        |
| `AUTH_URL`                                 | رابط الموقع                         |
| `SEED_ADMIN_EMAIL` / `SEED_ADMIN_PASSWORD` | بيانات المدير الأولي (للـ seed فقط) |
| `PAYMENT_PROVIDER`                         | `mock` \| `stripe` \| `paypal`      |
| `EMAIL_PROVIDER`                           | `mock` \| `smtp`                    |

> **الأمان:** لا تضع أي أسرار داخل الكود. جميع المفاتيح تُقرأ من متغيرات البيئة. ملف `.env` مستثنى من Git.

## 3) إعداد قاعدة البيانات

```bash
# توليد Prisma Client
npm run prisma:generate

# تطبيق المخطط على قاعدة البيانات
npm run prisma:migrate

# زراعة البيانات التجريبية (30 منتجاً، 10 عملاء، طلبات، كوبونات...)
npm run prisma:seed
```

## 4) التشغيل محلياً

```bash
npm run dev
```

الموقع على `http://localhost:3000` ولوحة التحكم على `/admin`.

## 5) عبر Docker (بديل)

```bash
docker compose up -d
```

يشغّل PostgreSQL و Redis والتطبيق. طبّق الهجرات والـ seed بعد أول تشغيل.

## النشر

### الواجهة (Vercel)

1. اربط مستودع GitHub بـ Vercel.
2. أضف متغيرات البيئة في إعدادات المشروع.
3. أمر البناء: `npm run build` (يشغّل `prisma generate` تلقائياً).
4. للإنتاج استخدم `npm run prisma:deploy` لتطبيق الهجرات.

### قاعدة البيانات

استخدم مزوداً مُدَاراً مثل **Neon** أو **Supabase** أو **Railway**، وانسخ رابط الاتصال إلى `DATABASE_URL`.

## إنشاء حساب المدير

يُنشأ تلقائياً عند تشغيل `npm run prisma:seed` باستخدام `SEED_ADMIN_EMAIL` و `SEED_ADMIN_PASSWORD` من ملف البيئة. **غيّر كلمة المرور الافتراضية في الإنتاج.**

## إعداد الدفع والشحن والبريد

جميع المزودات الخارجية مبنية بنمط **Interface + Mock Provider** قابل للاستبدال:

- **الدفع:** غيّر `PAYMENT_PROVIDER` إلى `stripe` أو `paypal` وأضف المفاتيح. بيانات البطاقة لا تُخزَّن على الخادم إطلاقاً (Tokenization + Hosted Fields).
- **البريد:** غيّر `EMAIL_PROVIDER` إلى `smtp` وأضف بيانات SMTP.
- **الشحن:** يُدار من لوحة التحكم (شركات، مناطق، تكاليف).

## النسخ الاحتياطي

- استخدم النسخ الاحتياطي التلقائي لمزود قاعدة البيانات (Neon/Supabase يوفران snapshots).
- أو `pg_dump` مجدولاً عبر cron.

## استكشاف الأخطاء

| المشكلة                     | الحل                                   |
| --------------------------- | -------------------------------------- |
| فشل الاتصال بقاعدة البيانات | تحقق من `DATABASE_URL` وأن الخدمة تعمل |
| خطأ Prisma Client           | شغّل `npm run prisma:generate`         |
| خطأ AUTH_SECRET             | ولّده بـ `npx auth secret`             |
